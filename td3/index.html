a. Informations pertinentes pour une carte

Pour chaque carte, il est pertinent de mémoriser :

  • Nom : Le nom de la carte.
  • Numéro : Le numéro de la carte dans le collecteur (1 à 135).
  • Puissance : Un entier entre 0 et 6.
  • Statistiques : Quatre valeurs pour l'amitié, l'aventure, la bravoure et la popularité.

b. Structure une_carte

Structure une_carte nom : chaîne de caractères numero : entier puissance : entier amitie : entier aventure : entier bravoure : entier popularite : entier Fin Structure

c. Structure les_cartes

Structure les_cartes cartes : tableau de 135 éléments de type une_carte Fin Structure

d. Structure une_collection

Structure une_collection nb_exemplaires : tableau de 135 entiers cartes : tableau de 135 éléments de type une_carte Fin Structure

e. Procédure cartes_manquantes

Procédure cartes_manquantes(collection : une_collection) Afficher "Cartes manquantes :" Pour i de 0 à 134 Si collection.nb_exemplaires[i] = 0 Alors carte <- collection.cartes[i] Afficher "Nom: ", carte.nom, ", Numero: ", carte.numero, ", Puissance: ", carte.puissance, ", Amitié: ", carte.amitie, ", Aventure: ", carte.aventure, ", Bravoure: ", carte.bravoure, ", Popularité: ", carte.popularite Fin Si Fin Pour Fin Procédure

f. Fonction exemplaires_multiples

Fonction exemplaires_multiples(collection : une_collection) : entier count <- 0 Pour i de 0 à 134 Si collection.nb_exemplaires[i] > 1 Alors count <- count + 1 Fin Si Fin Pour Retourner count Fin Fonction

g. Fonction collection_complete

Fonction collection_complete(collection : une_collection) : entier Pour i de 0 à 134 Si collection.nb_exemplaires[i] = 0 Alors Retourner 0 // Collection non complète Fin Si Fin Pour Retourner 1 // Collection complète Fin Fonction

h. Fonction recherche_carte

Fonction recherche_carte(collection : une_collection, nom : chaîne de caractères) : entier Pour i de 0 à 134 Si collection.cartes[i].nom = nom Alors Retourner i Fin Si Fin Pour Retourner -1 // Carte non trouvée Fin Fonction

i. Procédure reunir_collections

Procédure reunir_collections(c1 : Référence une_collection, c2 : une_collection) Pour i de 0 à 134 c1.nb_exemplaires[i] <- c1.nb_exemplaires[i] + c2.nb_exemplaires[i] Fin Pour Fin Procédure

j. Structure une_pochette

Structure une_pochette numeros : tableau de 3 entiers Fin Structure

k. Procédure ajout_pochette

Procédure ajout_pochette(collection : Référence une_collection, pochette : une_pochette) Pour i de 0 à 2 num <- pochette.numeros[i] - 1 collection.nb_exemplaires[num] <- collection.nb_exemplaires[num] + 1 Fin Pour Fin Procédure

l. Procédure ajout_plusieurs_pochettes

Procédure ajout_plusieurs_pochettes(collection : Référence une_collection, pochettes : tableau de une_pochette, n : entier) Pour i de 0 à n-1 ajout_pochette(collection, pochettes[i]) Fin Pour Fin Procédure

m. Procédure retrait_carte

Procédure retrait_carte(collection : Référence une_collection, numero : entier) Si collection.nb_exemplaires[numero - 1] > 0 Alors collection.nb_exemplaires[numero - 1] <- collection.nb_exemplaires[numero - 1] - 1 Fin Si Fin Procédure

n. Fonction comparaison_collections

Fonction comparaison_collections(c1 : une_collection, c2 : une_collection) : entier Pour i de 0 à 134 Si (c1.nb_exemplaires[i] > 0 et c2.nb_exemplaires[i] = 0) ou (c1.nb_exemplaires[i] = 0 et c2.nb_exemplaires[i] > 0) Alors Retourner 0 // Différentes Fin Si Fin Pour Retourner 1 // Identiques Fin Fonction

o. Fonction verification_faisabilite_echange

Fonction verification_faisabilite_echange(c1 : une_collection, c2 : une_collection, num1 : entier, num2 : entier) : entier Retourner c1.nb_exemplaires[num1 - 1] > 1 et c2.nb_exemplaires[num2 - 1] > 1 Fin Fonction

p. Procédure echange_cartes

Procédure echange_cartes(c1 : Référence une_collection, c2 : Référence une_collection, num1 : entier, num2 : entier) Si verification_faisabilite_echange(c1, c2, num1, num2) Alors c1.nb_exemplaires[num1 - 1] <- c1.nb_exemplaires[num1 - 1] - 1 c2.nb_exemplaires[num2 - 1] <- c2.nb_exemplaires[num2 - 1] - 1 c1.nb_exemplaires[num2 - 1] <- c1.nb_exemplaires[num2 - 1] + 1 c2.nb_exemplaires[num1 - 1] <- c2.nb_exemplaires[num1 - 1] + 1 Fin Si Fin Procédure
